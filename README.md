# Stya Yur / styayur

<img src="assets/brand/mark.svg" width="48" alt="Stya Yur personal mark" />

Building local-first software, developer tools, and open-source utilities. I work on tools that keep their data and core workflows on the user's machine, with clear boundaries between implemented features and experiments. Project repositories contain installation instructions, demonstrations, limitations, and verification records.

## Selected Projects

- [Publishing Workbench](https://github.com/styayur/publishing-workbench) — a local publishing editor with extension adapters and recoverable job journals.
- [Local Context Engine](https://github.com/styayur/local-context-engine) — Windows search with a deterministic Rust core and query compiler.
- [CodeForge Engine](https://github.com/styayur/codeforge-engine) — code transformation with verification and language-aware analysis.
- [STEM Visual Explorer](https://github.com/styayur/stem-visual-explorer) — a workspace for finding and comparing mathematics and physics resources.
- [Calligraphy Studio](https://github.com/styayur/calligraphy-studio) — an offline workbench for composing and comparing calligraphy.
- [Translation Kernel](https://github.com/styayur/translation-kernel) — browser translation primitives and reversible bilingual rendering.

Maturity assessments and their limits are maintained in the [portfolio evidence register](portfolio/maturity.json). A release number alone does not establish stability.
